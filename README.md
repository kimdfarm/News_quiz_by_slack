# 뉴스 기반 시사 상식 퀴즈 슬랙 봇 (News Quiz Slack Bot)

## 1. 목적

매일 수집되는 최신 뉴스(경제/IT 분야)를 바탕으로 핵심 팩트와 저자의 의견을 담은 맞춤형 퀴즈를 자동으로 생성하고, 슬랙 채널에서 팀원들이 간편하게 퀴즈를 풀고 피드백을 받을 수 있도록 하여 시사 상식 학습의 효율성을 높인다.

## 2. 기능

* **기능 1 (자동 수집 및 정형화):** 특정 뉴스 RSS 피드에서 최신 기사를 크롤링하여 팩트와 저자의견으로 파싱 후 DB에 1주일(TTL) 동안 저장
* **기능 2 (슬랙 기반 퀴즈 출제 및 응답):** 슬랙 채널에서 `@봇이름 [분야] 문제 내줘` 명령 시, RAG 및 LLM을 통해 4지선다형 퀴즈를 생성하여 동일 스레드에 답변

## 3. 사용 모델과 선택 근거 ★

* **생성 모델:** `gemma:3.4b` (또는 ollama 로컬 구동 모델)
* **임베딩 모델:** `sentence-transformers/all-MiniLM-L6-v2` (또는 KoSBERT 등 가벼운 오픈소스 임베딩)
* **근거:** 8GB VRAM 환경 및 학교 실습 가이드라인을 준수하기 위해 12B 미만의 경량 로컬 모델을 채택하였으며, 외부 API 비용 발생 없이 오프라인 구동이 가능함. (크롤링 및 대량 파싱 단계의 속도 보완을 위해 Groq API 무료 티어를 차안으로 병행 활용)
* **VRAM 계산:** 약 3.4GB ~ 4.5GB 소요 $\rightarrow$ 8GB VRAM 안에 안정적으로 들어감 ✅

## 4. 사용 스택

* **LangChain:** 문서 로드, 프롬프트 템플릿 관리 및 RAG 체인 파이프라인 구축
* **LangSmith:** LLM 호출 과정 및 RAG 검색 품질 추적(Tracing) 및 디버깅 **(필수)**
* **LangGraph:** (선택 적용 시) 멀티스텝 퀴즈 생성 및 채점 에이전트 플로우 제어

## 5. 실행 방법

1. `.env` 파일에 `SLACK_BOT_TOKEN`, `SLACK_APP_TOKEN` 설정 (절대 코드에 하드코딩 금지)
2. 터미널에서 Ollama 실행 및 모델 다운로드 (`ollama run gemma:3.4b`)
3. 의존성 패키지 설치 (`pip install -r requirements.txt`)
4. 슬랙 볼트 소켓 모드 실행 (`python slack_llm_bot.py`)
